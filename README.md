FAYRA Marketplace V4
====================
Seller Center yang lebih lengkap.

Fitur:
- Profil/edit toko
- Status verifikasi
- Seller upload produk
- Edit data produk melalui API
- Nonaktifkan produk
- Seller melihat order masuk
- Seller mengubah status order
- Wallet seller dasar
- Withdrawal endpoint dasar
- Buyer marketplace + COD
- Order dan stok

Demo:
Seller: seller@fayra.local / seller123
Admin: admin@fayra.local / admin123

Menjalankan:
1. Node.js 18+
2. npm install
3. npm run dev
4. http://localhost:3000

Catatan penting:
Masih MVP lokal. Password plaintext dan image masih placeholder/emoji.
Belum production-ready dan belum menerima uang sungguhan.
